# Reproducibility record fields

A reproducible verification record identifies the source commit, source digest, tool versions, exact commands, exit codes and raw output paths. A live record additionally binds network, contract address, transaction hash, caller, method, arguments, finality, execution outcome and finalized readback.

Keep expected fixture labels separate from model observations, and local runs separate from network consensus. Record failed and unexecuted cases explicitly. A current membership read may differ from a historical admission after root revocation.
